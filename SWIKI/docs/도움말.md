# 📖 SWIKI 문법 도움말

본 문서는 SWIKI에서 지원하는 특수 문법과 마크다운 작성법을 안내합니다. 모든 편집기 기능은 **[대문](?page=대문)**에서 직접 테스트해 보실 수 있습니다!

## 1. 문단 제목 (헤딩) 및 목차

나무위키(the seed) 문법과 동일하게 문단 제목을 작성할 수 있습니다. 작성 시 자동으로 **숫자 넘버링(1. 1.1.)**이 부여됩니다.

```markdown
= 1단계 문단 =
== 2단계 문단 ==
=== 3단계 문단 ===
```

또한, 문서 내용 중에 `[목차]` 라고 한 줄을 적어두시면 그 위치에 목차가 렌더링됩니다. 따로 기재하지 않으면 문서 맨 위(분류 아래)에 자동 생성됩니다.

## 2. 텍스트 꾸미기 및 유튜브 삽입 (나무마크 호환)

나무위키에서 사용하는 주요 문법(나무마크)을 그대로 사용할 수 있습니다!

```markdown
'''굵은 글씨'''
''기울인 글씨''
--취소선-- 또는 ~~취소선~~
__밑줄__
^^위첨자^^ 와 ,,아래첨자,,

[youtube(유튜브영상ID)]  => 유튜브 영상이 깔끔하게 삽입됩니다!
```

## 3. 접기/펼치기 및 정렬 (특수 문법)

```markdown
{{{#!folding [접기 제목]
여기에 숨길 내용을 적으세요.
}}}

{{{#!wiki style="text-align:center"
가운데 정렬할 텍스트입니다.
}}}
```

## 4. 나무위키 고급 표 (Table)

표의 셀 색상, 정렬, 너비, 병합(셀 합치기) 등 나무위키 고급 표 문법을 100% 지원합니다.

```markdown
||<tablewidth=100%><tablebgcolor=#f5f5f5><:> 가운데 정렬 ||<)> 오른쪽 정렬 ||
||<rowbgcolor=#e0f7fa><-2> 가로로 2칸 합치기 (Colspan) ||
||<bgcolor=red><color=white> 빨간 배경 흰 글씨 || 내용 ||
```

## 5. 특수 매크로 (시간, 수식 등)

나무위키에서 자주 쓰이는 특수 매크로도 정상적으로 작동합니다.
* `[date]` : 현재 날짜와 시간으로 치환됩니다.
* `[age(2000-01-01)]` : 2000년생의 만 나이로 자동 계산됩니다.
* `[dday(2030-01-01)]` : 특정 날짜까지의 디데이를 표시합니다.
* `[math(x^2 + y^2 = z^2)]` : 수식을 수학 기호로 깔끔하게 렌더링합니다.
* `[br]` : 줄바꿈을 강제로 적용합니다.
* `[clearfix]` : 떠 있는 요소(Float) 등의 정렬을 초기화합니다.
* `[ruby(텍스트, ruby=루비)]` : 글자 위에 작은 글씨(루비 문자)를 달아줍니다.

## 6. 넘겨주기 (리다이렉트) 및 역링크

* **넘겨주기:** 문서 맨 첫 줄에 `#redirect 이동할문서` 또는 `#넘겨주기 이동할문서` 를 적어두면, 해당 문서로 들어왔을 때 자동으로 도착 문서로 튕겨냅니다!
* **역링크:** 상단의 '역링크' 버튼을 누르면, 이 문서를 링크하고 있는 다른 모든 문서들의 목록을 즉시 탐색해서 보여줍니다.

## 7. 하위 문서 및 경로 링크

* 문서 이름을 `상위문서/하위문서`로 짓고 작성하면 자동으로 뷰어 최상단에 상위 문서로 돌아갈 수 있는 **계층형 네비게이션(Breadcrumbs)** 이 생깁니다.
* `[[/하위문서]]` : 현재 문서가 `마인크래프트`라면 `마인크래프트/하위문서`로 자동으로 연결됩니다.
* `[[../]]` : 현재 문서의 상위 문서로 바로가기 링크를 생성합니다.

## 8. 문서 분류 (카테고리)

문서를 특정 분류에 소속시키려면 다음 문법을 문서 어디에나 삽입하세요.
문서 뷰어 최상단에 분류 박스가 생성되며, 클릭하면 해당 분류에 속한 **모든 문서 목록**을 볼 수 있는 동적 페이지로 이동합니다.

```markdown
[[분류:마인크래프트]]
[[분류:도움말]]
```

## 3. 타 문서 링크 및 옵시디언 형식 링크

다른 문서로 쉽게 이동할 수 있는 위키 링크(Wiki Link) 기능입니다.

```markdown
[[서버규칙]]             => 서버규칙 문서로 연결
[[서버규칙|서버 규칙 보기]] => 보여지는 텍스트를 다르게 지정
```

## 4. 틀 (Template) 불러오기

자주 사용하는 경고문이나 표, 알림 등을 별도 문서(예: `틀_경고`, `틀_마을목록` 등)로 만들어두고, 여러 문서에서 재활용할 수 있습니다. 
*참고: Windows 환경에서는 문서 이름에 `:`(콜론)을 사용할 수 없으므로 `틀_이름` 형식을 권장합니다.*

문서 내에 아래 문법을 사용하면 해당 틀 문서의 내용이 그 자리에 고스란히 펼쳐집니다! 최대 3중첩까지 지원됩니다.

```markdown
[include(틀_경고)]
[include(틀_마을목록)]
```
> **[예시 미리보기]**
> 아래 틀을 실제로 불러오면 이렇게 렌더링됩니다!
> [include(틀_경고)]
> [include(틀_마을목록)]

## 5. 주석 (Footnote)

문서 내에 부연 설명이 필요할 때 사용하는 주석 기능입니다. 본문에서는 윗첨자 번호(예: [1])로 작게 표시되며 클릭하면 문서 맨 아래의 각주 모음으로 이동합니다.

```markdown
마인크래프트는 최고의 샌드박스 게임입니다.[* 물론 사람마다 의견은 다를 수 있습니다.]
```

## 6. 수학 수식 (LaTeX) 및 다이어그램

복잡한 수식을 지원합니다.
```markdown
인라인 수식: $E = mc^2$
블록 수식:
$$
\frac{-b \pm \sqrt{b^2-4ac}}{2a}
$$
```

## 7. HTML 및 자바스크립트 실행 지원

이 위키 엔진은 마크다운 내에 포함된 HTML, CSS, Javascript를 실제 브라우저에서 안전하게 실행해줍니다. 단, 실시간 미리보기 모드에서는 스크립트 실행이 잠시 멈춥니다(수정 중 오류 방지).

```html
<button onclick="alert('환영합니다!')" style="padding:10px; background:#4CAF50; color:white; border:none; cursor:pointer;">
  클릭해보세요!
</button>
```

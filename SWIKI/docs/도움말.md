# 📖 SWIKI 문법 도움말

본 문서는 SWIKI에서 지원하는 특수 문법과 마크다운 작성법을 안내합니다. 모든 편집기 기능은 **[대문](?page=대문)**에서 직접 테스트해 보실 수 있습니다!

## 1. 문단 제목 (헤딩) 및 목차

나무위키(the seed) 문법과 동일하게 문단 제목을 작성할 수 있습니다. 작성 시 자동으로 **숫자 넘버링(1. 1.1.)**이 부여됩니다.

```markdown
= 1단계 문단 =
== 2단계 문단 ==
=== 3단계 문단 ===
```

또한, 문서 내용 중에 `[목차]` 라고 한 줄을 적어두시면 그 위치에 목차가 렌더링됩니다. 따로 기재하지 않으면 문서 맨 위(분류 아래)에 자동 생성됩니다.

## 2. 텍스트 꾸미기 및 유튜브 삽입 (나무마크 호환)

나무위키에서 사용하는 주요 문법(나무마크)을 그대로 사용할 수 있습니다!

```markdown
'''굵은 글씨'''
''기울인 글씨''
--취소선-- 또는 ~~취소선~~
__밑줄__
^^위첨자^^ 와 ,,아래첨자,,

[youtube(유튜브영상ID)]  => 유튜브 영상이 깔끔하게 삽입됩니다!

|| 1번 칸 || 2번 칸 ||
|| 3번 칸 || 4번 칸 ||
(기본적인 나무마크 표 형식도 지원합니다)
```

## 3. 문서 분류 (카테고리)

문서를 특정 분류에 소속시키려면 다음 문법을 문서 어디에나 삽입하세요.
문서 뷰어 최상단에 분류 박스가 생성되며, 클릭하면 해당 분류에 속한 **모든 문서 목록**을 볼 수 있는 동적 페이지로 이동합니다.

```markdown
[[분류:마인크래프트]]
[[분류:도움말]]
```

## 3. 타 문서 링크 및 옵시디언 형식 링크

다른 문서로 쉽게 이동할 수 있는 위키 링크(Wiki Link) 기능입니다.

```markdown
[[서버규칙]]             => 서버규칙 문서로 연결
[[서버규칙|서버 규칙 보기]] => 보여지는 텍스트를 다르게 지정
```

## 4. 틀 (Template) 불러오기

자주 사용하는 경고문이나 표, 알림 등을 별도 문서(예: `틀_경고`, `틀_마을목록` 등)로 만들어두고, 여러 문서에서 재활용할 수 있습니다. 
*참고: Windows 환경에서는 문서 이름에 `:`(콜론)을 사용할 수 없으므로 `틀_이름` 형식을 권장합니다.*

문서 내에 아래 문법을 사용하면 해당 틀 문서의 내용이 그 자리에 고스란히 펼쳐집니다! 최대 3중첩까지 지원됩니다.

```markdown
[include(틀_경고)]
[include(틀_마을목록)]
```
> **[예시 미리보기]**
> 아래 틀을 실제로 불러오면 이렇게 렌더링됩니다!
> [include(틀_경고)]
> [include(틀_마을목록)]

## 5. 주석 (Footnote)

문서 내에 부연 설명이 필요할 때 사용하는 주석 기능입니다. 본문에서는 윗첨자 번호(예: [1])로 작게 표시되며 클릭하면 문서 맨 아래의 각주 모음으로 이동합니다.

```markdown
마인크래프트는 최고의 샌드박스 게임입니다.[* 물론 사람마다 의견은 다를 수 있습니다.]
```

## 6. 수학 수식 (LaTeX) 및 다이어그램

복잡한 수식을 지원합니다.
```markdown
인라인 수식: $E = mc^2$
블록 수식:
$$
\frac{-b \pm \sqrt{b^2-4ac}}{2a}
$$
```

## 7. HTML 및 자바스크립트 실행 지원

이 위키 엔진은 마크다운 내에 포함된 HTML, CSS, Javascript를 실제 브라우저에서 안전하게 실행해줍니다. 단, 실시간 미리보기 모드에서는 스크립트 실행이 잠시 멈춥니다(수정 중 오류 방지).

```html
<button onclick="alert('환영합니다!')" style="padding:10px; background:#4CAF50; color:white; border:none; cursor:pointer;">
  클릭해보세요!
</button>
```
